# Aslisite Gym Template

One React/Vite master template serving many prospect demos from unique URL slugs.

## Demo routes

- `/fitness-edge-prime`
- `/test-gym`

The root `/` renders the generic sample template.

## Add a prospect

1. Add a config file under `src/prospects/`.
2. Register its slug in `src/prospects/index.js`.
3. Push to `main`; Vercel redeploys the single project.

No separate repository or Vercel project is required per prospect.
